Antes de que preguntes

¿Qué pasa si ARCA se cae?

Si los servidores de ARCA no responden en el momento de facturar un comprobante, ese comprobante queda marcado con el error puntual (podés ver el detalle) y sigue disponible como pendiente — no se pierde ni se factura mal. Podés reintentarlo vos mismo con un click, o simplemente correr de nuevo "Facturar todo lo pendiente" más tarde, cuando ARCA vuelva a andar.

¿Cómo sé que no voy a facturar algo dos veces?

El sistema reconoce el ID de transacción de cada comprobante (por ejemplo, el de un pago de Mercado Pago) y, si ya existe otro comprobante facturado con ese mismo ID, no te deja facturarlo de nuevo — te avisa el conflicto en vez de duplicar la factura.
